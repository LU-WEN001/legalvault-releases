1.0.0 升级到 1.0.1 涉及基础运行环境变更，需要下载完整安装包覆盖安装。请先保存工作并退出旧版；Windows 使用原安装目录，macOS 替换“应用程序”中的旧版应用。现有设置、会话和工作资料保留。

当前安装包尚未通过 Apple 公证或 Windows 发行者证书签名，系统可能显示安全确认提示；macOS 升级后也可能要求重新授权钥匙串访问。
